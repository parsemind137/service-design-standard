# Service Design Standard (SDS)

A generalized standard for service design. Applicable to any domain.

## Quick Start

1. Read [STANDARD.md](./versions/1.0.0/STANDARD.md) — full text of the current version
2. Use [examples](./versions/1.0.0/STANDARD.md#examples) as a template for your project
3. Check compliance against [criteria](./versions/1.0.0/COMPLIANCE.md)
