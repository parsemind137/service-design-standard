# Contributing

Thank you for your interest in Service Design Standard! Any contribution is welcome.

## Questions

If something is unclear — create an Issue with the `question` label.

## How to Contribute

### Report a Bug

1. Open a new Issue with the `bug` label
2. Describe the problem: what you expected and what actually happens
3. Specify the standard version (from CHANGELOG)

### Suggest an Improvement

1. Open a new Issue with the `enhancement` label
2. Describe your proposal and rationale
3. Discuss with maintainers before implementing
